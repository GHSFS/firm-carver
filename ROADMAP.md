# FirmCarver Roadmap

This document tracks shipped capabilities and planned firmware forensics, container parsing, and static vulnerability auditing features for `fcarver`.

---

## Shipped Capabilities

- [x] **Hardcoded IPv4/IPv6 & External Telemetry Domain Classifier (`v0.12.0`)** — Standalone zero-dependency network endpoint extractor and domain auditor (`src/domain_audit/`) extracting URLs, IPv4/IPv6 addresses, and hostnames from binary firmware dumps, raw flash partitions, and filesystem trees; URI parser supporting `http`, `https`, `ftp`, `tftp`, `telnet`, `ws`, `wss`, `mqtt`, `mqtts` with embedded credential extraction; RFC-compliant IP address scope classifier (Public, RFC 1918 Private, Loopback, Link-Local, CGNAT, Documentation, Multicast, Broadcast); functional domain classifier (Telemetry/Analytics, Firmware Update OTA, Dynamic DNS, Cloud/CDN, NTP, Local Network); security rule engine detecting cleartext OTA URLs (`NET-CLEAR-001`), cleartext APIs (`NET-CLEAR-002`), hardcoded public IPs (`NET-HARDIP-001`), dynamic DNS providers (`NET-DDNS-001`), insecure protocols (`NET-INSEC-001`), and embedded URI credentials (`NET-AUTH-001`); recursive directory scanner with symlink loop guards; memory zeroing (`Zeroize`); dedicated CLI subcommand `fcarver domain-audit` (`--min-severity`, `--filter`, `--no-private`, `--out`, `--offset`, `--json`); 13 integration tests passing.
- [x] **Broadcom & MediaTek NVRAM Default Table Extractor (`v0.11.0`)** — Standalone zero-dependency parser for Broadcom flash NVRAM headers (`FLSH` / `0x48534C46` Little-Endian and `0x464C5348` Big-Endian) (`broadcom.rs`, `types.rs`) with 8-bit additive checksum verification; null-delimited `key=value\0` string table extractor; packed strings table scanner (`scan_packed_strings_tables`) recovering static NVRAM tables in compiled `.rodata` sections and bootloader memory dumps; MediaTek and Ralink `.dat` line-delimited configuration parser (`mediatek.rs`); MediaTek Factory / EEPROM flash partition decoder (`parse_mediatek_eeprom`) extracting SoC chip IDs (MT7620, MT7628, MT7621, RT2880, MT7603, MT7612, MT7615, MT7915), MAC addresses, NIC flags, and RF calibration tables; security audit rule engine (`rules.rs`) checking default Wi-Fi passwords (`NVRAM-WIFI-001`), insecure open/WEP wireless (`NVRAM-WIFI-002`), static WPS PINs (`NVRAM-WPS-001`), default admin credentials (`NVRAM-CRED-001`), diagnostic backdoors (`NVRAM-FLAG-001`), and cleartext management URLs (`NVRAM-SVC-001`); continuous stream carving under `CarvedKind::Nvram`; safe `.env` file export; `zeroize` memory scrubbing; dedicated CLI subcommand `fcarver nvram` (`--audit`, `--list`, `--extract`, `--json`, `--format`, `--offset`); 11 integration tests passing.
- [x] **UBI & UBIFS Volume Header Parser & Filesystem Reconstructor (`v0.10.0`)** — Standalone zero-dependency parser for UBI physical layer (`UBI#` / `0x55424923`) and Volume Identifier headers (`UBI!` / `0x55424921`) with IEEE 802.3 CRC32 verification; UBI Layout Volume (`0x7FFFFFFF`) table record parser decoding volume names, reserved eraseblocks, and volume types; automatic PEB geometry detection (16 KiB through 2 MiB) with LEB stream reassembly; UBIFS on-flash node decoder (`node.rs`) parsing common headers (`0x06101831`), Superblock nodes (`UBIFS_SB_NODE` format v4/v5, LEB geometry, filesystem UUID), Master nodes (`UBIFS_MST_NODE`, commit sequence, space accounting, highest inum), Inode nodes (`UBIFS_INO_NODE`, UNIX permissions, UID/GID, file size, inline symlink targets), and Directory Entry nodes (`UBIFS_DENT_NODE`, parent key, child inum, filename); directory tree reconstruction engine (`reconstruct.rs`) mapping parent-child inode graphs, generating formatted UNIX file listings (`drwxr-xr-x`, `lrwxrwxrwx`), symlink target resolution, and safe disk extraction with path traversal defenses; continuous flash partition carver (`carver.rs`) discovering embedded UBI and UBIFS partitions in raw firmware dumps; dedicated `ubifs` CLI subcommand (`--list`, `--extract`, `--json`, `--offset`, `--peb-size`); deterministic synthetic fixture generators.
- [x] **JFFS2 Flash Filesystem Carver & Node Reconstructor (`v0.9.0`)** — Standalone parser and carver for JFFS2 NOR/NAND flash partitions supporting Little-Endian (`0x85 0x19`) and Big-Endian (`0x19 0x85`); validation of cleanmarker (`0x2003`), dirent (`0xE001`), and inode (`0xE002`) node CRC32 signatures; multi-chunk inode data reassembly with RTIME and Zlib decompression; bounds-checked memory safety protecting against RTIME dictionary corruption (CVE-2024-57850); tombstone-aware directory resolution and path traversal extraction defense; dedicated `jffs2` CLI subcommand (`--list`, `--extract`, `--json`, `--offset`); deterministic synthetic fixture generators.
- [x] **Hardcoded TLS Certificate & Expired Root CA Scanner (`v0.8.0`)** — Zero-dependency pure-Rust ASN.1 DER parser and RFC 4648 Base64 PEM decoder for X.509 certificates and PKCS#1/PKCS#8 private keys; security auditing rules for expired certificates (`CERT-EXP-001`), impending expiry (`CERT-EXP-002`), weak/broken signature algorithms (MD2/MD5 `CERT-SIG-001`, SHA-1 `CERT-SIG-002`), weak RSA key lengths (512-bit `CERT-KEY-001`, 1024-bit `CERT-KEY-002`), self-signed certificates (`CERT-SELF-001`), hardcoded private key matching (`CERT-PRIV-001`), and anomalous validity lifespans (`CERT-VAL-001`); recursive directory walker, single-file scanner, and raw buffer stream carver for embedded DER/PEM blocks; deterministic synthetic fixture generator (`fcarver synth-fw -t cert-store`, `cert-blob`); modular CLI decomposition into `src/commands/` dropping `src/main.rs` to 18 lines.
- [x] **Embedded Web Management Interface & CGI Script Static Auditor (`v0.7.0`)** — Static vulnerability and security analysis engine for carved router `/www` web hierarchies, shell CGI scripts, and embedded web handlers; detection of command injection vulnerabilities (`system()`, `popen()`, unescaped `$QUERY_STRING`), unauthenticated administrative routes (`reboot`, `factory_reset`, `upgrade`, `backup`), backdoor cookies (`dlink_uid=0`), hardcoded credentials (`admin:admin`), path traversal (`cat $file`), and sensitive information disclosures (`/etc/shadow`, `/tmp/nvram`, `/proc/kmsg`); recursive directory tree scanning with symlink loop guards, virtual in-memory tree scanning, and dedicated `cgi-audit` CLI subcommand (`--min-severity`, `--out`, `--json`); deterministic synthetic web tree fixtures.
- [x] **Cryptographic Hash Digest & Integrity Attestation Generator (`v0.6.0`)** — NIST SHA-256 (32B), SHA-512 (64B), and BLAKE3 (32B) cryptographic hashing engines; constant-time string comparisons protecting against timing side-channel attacks; attestation manifest generator scanning entire firmware binaries alongside individual container headers and carved partition streams; verification engine verifying whole-file and partition-level digests with tamper and boundary detection; dedicated `integrity` CLI subcommand (`--out`, `--verify`, `--algo`, `--json`); deterministic synthetic firmware fixture generator.
- [x] **Entropy-Guided Bootloader & Kernel Boundary Slicer (`v0.5.0`)** — Sliding-window Shannon entropy profiling and Chi-square goodness-of-fit testing; inflection point detection for compression rises, compression drops, padding entrances, and exits; automated contiguous partition slicing and disk extraction; dedicated `slice` CLI subcommand with `--window`, `--step`, `--threshold`, `--plot`, `--out`, and `--json`; deterministic synthetic multi-stage firmware fixture generator.
- [x] **MIPS / ARM / RISC-V Cross-Architecture Shellcode Detector (`v0.4.0`)** — Statistical instruction set analyzer scoring MIPS32 (EB/EL), ARMv7, Thumb-2, AArch64, RV32, and RV64; exploit payload pattern matcher identifying NOP sled landing pads, interactive `/bin/sh` or `/bin/busybox` string pointers, and architecture-specific Linux `sys_execve` syscall sequences (MIPS 4011, ARM 11, AArch64 221, RISC-V 221); pure-Rust multi-architecture disassembler; dedicated `arch-detect` CLI subcommand with `--offset`, `--length`, `--min-confidence`, `--disasm`, and `--json`.
- [x] **Device Tree Blob (FDT) Disassembler & Peripheral Hardware Mapping (`v0.3.0`)** — Standalone Flattened Device Tree parser for v1-v17 DTB containers with bounds-checked header and token parsing; memory reservation map decoder; full recursive node hierarchy parser with smart DTS value formatting (string lists, cell arrays, MAC byte sequences); hardware peripheral extractor mapping board model/compatible, chosen bootargs/stdout-path, RAM ranges, UART serial consoles, SPI flash MTD partitions, Ethernet MAC interfaces, and CPU cores; CLI subcommand `fcarver fdt` with `--dts`, `--hardware`, `--json`, and `--offset`.
- [x] **SquashFS v4 Directory & Inode Metadata Extractor (`v0.2.0`)** — Standalone parser for SquashFS 4.0 superblock, supporting little-endian and big-endian systems; multi-block `MetadataReader` with Deflate decompression; directory table walking, full file tree recovery, permissions and symlink resolution, and dedicated `squashfs` CLI subcommand (`--list`, `--json`, `--offset`).
- [x] **Core Firmware Container Parser (U-Boot/TRX/FDT), Magic-Stream Carving Engine & Vulnerability Scanner (`v0.1.0`)** — Zero-dependency U-Boot `uImage` (Magic `0x27051956` big-endian with dual 32-bit CRC calculation), Broadcom `TRX` header (`0x30304448` / `HDR0` with 3 partition offsets), and Flattened Device Tree blobs (`0xD00DFEED` / FDT); multi-format magic-byte stream carver for SquashFS 4.0 (`sqsh`/`hsqs`), CramFS, Gzip, LZMA, and XZ; static firmware vulnerability and backdoor scanner for embedded RSA/EC/OpenSSH/PKCS#8 private keys, `/etc/shadow` root password hashes, unauthenticated `telnetd -l /bin/sh` backdoors, and `nc -e /bin/sh` reverse shells; deterministic synthetic firmware generator (`fcarver synth-fw`, `inspect`, `carve`, `audit`).

## Planned Milestones

### Filesystem Metadata & Deep Partition Analysis
- [ ] **CramFS Deep Directory Walker & Symlink Auditor (`src/cramfs_walk.rs`)** — Traverse CramFS directory headers and metadata records, checking for path traversal or malicious dangling symlinks.
- [ ] **YAFFS2 NAND Flash Filesystem Carver (`src/yaffs2.rs`)** — Carve and reconstruct raw Flash Translation Layer (FTL) partitions, assembling YAFFS2 chunk tags and object headers into a navigable filesystem tree.
- [ ] **Ext2/Ext3/Ext4 Raw Disk Image Inode Walker (`src/extfs.rs`)** — Locate and parse standard superblock and block group descriptors in raw firmware images, recovering directory trees, file extent trees, and deleted inode traces.

### Architecture & Code Forensics
- [ ] **ELF Header & Shared Library Dependency Resolver (`src/elf_resolver.rs`)** — Inspect carved binary executables (`0x7F454C46`), reading dynamic symbols (`DT_NEEDED`), interpreter paths (`/lib/ld-uClibc.so.0`), and non-stripped debug information.

### Packaging & Supply Chain Security
- [ ] **Vendor Firmware Container Unpacker (`src/vendor_pkg.rs`)** — Support proprietary encapsulation headers including MikroTik NPK, AVM Fritz!Box, Netgear CHK, D-Link SHRS, and Huawei update packages.
- [ ] **Firmware Modification & Repackaging Engine (`src/repack.rs`)** — Recompute container checksums and rebuild valid U-Boot or TRX firmware blobs after modifying carved rootfs payloads or updating security configurations.
- [ ] **SARIF & CycloneDX 1.5 Firmware SBOM Exporter (`src/sbom_export.rs`)** — Export firmware vulnerability audit findings, extracted software components, and filesystem manifests into standardized SARIF and CycloneDX JSON formats.
